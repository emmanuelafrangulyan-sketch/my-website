# Welcome to the Tiki Islands 🌺

*Created by Emul. Fueled by coconuts. Governed by absolutely no logic.*

A playful single-page website set in a made-up tropical archipelago:

- **Interactive island map**: seven islands with their own landmarks, dotted sailing routes, boats, fish, drifting clouds and hidden Easter eggs. Hover to peek, click to zoom in and sail to that island's section.
- **Real day/night cycle**: the map follows the actual sun over Yerevan (Asia/Yerevan time), moving through dawn, sunrise, daytime, sunset, dusk and night. A slider lets you preview any time of day.
- **The Tipsy Tiki**: Emul the bartender shakes up random tropical cocktails, with a shaker sound.
- **Hula Heaven**: a luau drum beat and a carved sign full of island jokes.

Everything lives in `index.html` (plain HTML/CSS/JS, no build step), so it works on GitHub Pages as-is.
